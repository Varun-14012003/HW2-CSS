IDs vs Classes

An ID is unique, so it can be used on only one element in a page, and it is selected in CSS with the # symbol (for example #button1). A class can be reused on many elements, one element can have several classes, and it is selected with the . symbol (for example .box). IDs are used to style or identify one specific element, while classes are used for styles shared by a group of elements. An ID selector also has higher specificity than a class selector, so if both set the same property, the ID wins. IDs can also be used for links that jump to a section of a page and for finding an element in JavaScript with getElementById.
