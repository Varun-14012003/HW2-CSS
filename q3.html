The text-shadow property takes four values in this order: horizontal offset, vertical offset, blur radius and color. The first value (4px) is the horizontal offset, which moves the shadow 4px to the right (a negative value would move it left). The second value (4px) is the vertical offset, which moves the shadow 4px down (a negative value would move it up). The third value (6px) is the blur radius, which controls how soft the shadow's edges are: 0 gives a sharp shadow, and larger values make it more blurred. The fourth value (red) is the color of the shadow.
